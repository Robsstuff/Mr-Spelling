SYLLABLE TYPES

Watch the Video

The consonant LE syllable type always appears at the end of a word. The method: count back 3 letters from the end (finding the C in CLE), then chop there to split the syllables. If the first part is a closed syllable (ends in a consonant), the vowel is short. If it is an open syllable (ends in a vowel) or a vowel team, the vowel is long.

HOW IT WORKS

The Rule

Consonant LE — Count Back 3, Then Chop
1

Find the word ending in -CLE, -BLE, -DLE, -TLE, -GLE, -PLE etc. (consonant + LE)

2

Count back 3 letters from the end and chop there to split into syllables

3

Look at the first syllable: if it ends in a consonant (closed) → short vowel. If it ends in a vowel (open) → long vowel

cat tle → closed syllable → short vowel: cattle
A ble → open syllable → long vowel: able
Nee dle → vowel team → long vowel: needle

WATCH OUT

Tricky Consonant LE Words

These words need extra attention
people

peo•ple — the first syllable has a vowel team (eo) making a long /ee/ sound. The consonant LE rule still applies — it is just an unusual first syllable type.

circle / purple

The first syllable is R-controlled (cir•cle, pur•ple). R changes the vowel sound, so it does not fit neatly into "short" or "long" — it is a third syllable type. The count-back-3 method still works to chop the syllables.

muscle / castle

These look like they should split easily but have silent consonants in the middle — the SC in muscle and the ST in castle include a letter that is not pronounced. The count-back-3 still applies from the end.
